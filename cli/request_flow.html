thesis_rlm request flow

Both pipelines call the same llama-server on the Colab GPU through a Cloudflare tunnel. The fiche calls it directly. The note goes through rlm-cli, which can only talk to Ollama or hosted providers, so a local shim poses as Ollama and forwards to llama-server.

Fiche goes direct

The fiche sets temperature, top_k and token limits per step. It talks to llama-server through the tunnel and refuses to start without QWEN_SERVER_URL.

Why the shim exists

rlm-cli has no setting for a custom OpenAI URL, and it sends no sampling parameters. The shim answers its Ollama probe, adds the note's sampling, and forwards each request to the tunnel.

rlm-cli patch

Stock rlm-cli 0.5.0 only looks up Ollama models in interactive mode. The note uses rlm run, so the repo ships a patched copy in cli/rlm-cli/. Install it with cli/install.sh.
