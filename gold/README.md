# GOLD references

`grille_annotation.md` is the 14-section grid every fiche fills (the target schema;
`scripts/fiche/render.py` mirrors its order). The rest of this folder is what runs are judged against.

Hand-built reference artifacts for judging pipeline runs. **Not generated by the
pipeline**: written directly from `data/2027Bourse.parquet` (introduction
pp.11-36, conclusion pp.611-642, the three part openings, and targeted reads of
the body chapters), with every citation verified against the parquet.

| thesis | file | words | verified |
|---|---|---|---|
| 2027Bourse | `2027Bourse_fiche_GOLD.md` | ~2,900 | 0 wrong, 0 off-by-one |
| 2027Bourse | `2027Bourse_note_GOLD.md` | 2,051 | 43/43 anchors hand-confirmed |
| daley_thesis | `daley_thesis_fiche_GOLD.md` | ~2,600 | 40/40 anchors hand-confirmed |
| daley_thesis | `daley_thesis_note_GOLD.md` | 1,700 | 29/29 anchors hand-confirmed |

**All citations are PARQUET pages** — what the pipeline sees. Printed pages
differ: Bourse offset **0**, Daley offset **+11** (`printed = parquet - 11`).
Run `verify_citations.py --show-offset` on any new thesis before judging it.

The two theses are deliberately different shapes: Bourse is 697 pp. of French
SHS with explicit research questions and hypotheses; Daley is 147 pp. of English
astronomy with **neither** — objectives are stated declaratively and the only
occurrence of "hypothesis" is statistical (p. 115). A pipeline that scores well
on both is genuinely discipline-agnostic.

## How to use

```bash
# 1. objective comparison against the gold
python3 scripts/tools/score_against_gold.py \
    results/2027Bourse/2027Bourse_fiche.md \
    gold/2027Bourse_fiche_GOLD.md \
    data/2027Bourse.parquet

# 2. per-citation verdicts on the candidate
python3 scripts/tools/verify_citations.py \
    results/2027Bourse/2027Bourse_fiche.md data/2027Bourse.parquet

# 3. score the subjective dimensions by hand with the rubric below
```

The gold is a **reference, not a ceiling**. A run that cites pages the gold
omits is not penalised — `score_against_gold.py` reports those separately as
`candidate-only pages`. Verify them; if they hold up, the run found something
the gold missed.

## Calibration — what the scorer reports on known runs

| run | length | anchor recall | verify_citations |
|---|---|---|---|
| gold | 2,051 w | 100% | 31 OK / 0 wrong |
| 27B `20260528_170434` (best) | 1,980 w (97%) | **48.9%** | 14 OK / 0 wrong |
| 9B `9B_20260609_174531` | 1,411 w (69%) | **26.7%** | fabricated pages |

Anchor recall separates the two 27B/9B runs by ~22 points, so it is a usable
signal on its own. Note that `anchor precision` in the scorer only checks the
cited page exists and is non-empty — the 9B scored 100% there while fabricating
citations. **Precision is only meaningful via `verify_citations.py`.**

# RUBRIC

> For the **judging procedure** — hard gates, catastrophic misses, verdict
> format and progress tracking — see `EVALUATION.md`. This file holds the
> per-section anchors that the judge calibrates against.

## Fiche — 14 sections × 10 = 140

Score each section 0-10. Anchors: **0** absent/`[Non renseigné]` when the content
exists in the thesis · **3** present but generic, no page anchors · **6** correct
and anchored but thin vs gold · **9** matches gold in substance · **10** equals or
exceeds gold.

| # | section | what a 10 looks like (see gold) |
|---|---|---|
| 1 | Métadonnées | all 6 fields exact |
| 2 | Mots-clés | author's keywords + 2-3 justified additions |
| 3 | Thèse centrale | names the 3 phases *and* the recursive effect (p. 612, p. 27) |
| 4 | Questions de recherche | all 4 (pp. 20-21) + the 3 methodological ones (p. 29) |
| 5 | Réponses | one verbatim-anchored answer per question, from the conclusion |
| 6 | Hypothèses | principale + 3 secondaires, each anchored |
| 7 | Méthodologie | 4 bullets; names Pyllica/Postgres/word2vec/1516 chroniques *and* the stated limits (p. 625) |
| 8 | Fil rouge | one sentence: concept + author + page + what it links |
| 9 | Plan | real part titles, each with what it *demonstrates* (not its topic) |
| 10 | Cadre théorique | Foucault principal + 5-6 secondaires, each with concept + page + role |
| 11 | Concepts clés | 5-6 concepts, each SENS verbatim + ORIGINE |
| 12 | Ancrage empirique | the 1826/1856 diptych, the 60k→190k figures, the *grumeaux* result |
| 13 | Opposition | 4-5 named positions (Shackle, Tetlock, Tétu/Mouillaud, Lavoinne) |
| 14 | Apport principal | théorique / empirique / méthodologique / critique, each specific |

## Note

The note rubric lives in **`EVALUATION.md`** (6 judged dimensions, 60 pts, with
explicit "different but valid" allowances).

It is deliberately *not* threshold-based. An earlier draft of this file scored
the note on counts — "≥10 quotes", "≥6 named actors" — which rewards imitating
the gold rather than understanding the thesis. The gold was written by a far
larger model; a 27B run that cites less but stays correct and coherent is not
worse for it. Citation *accuracy* is a hard gate (G1); citation *density* is not
scored at all.

### Body-chapter coverage (the usual failure)

Model notes reliably cover the introduction and conclusion and thin out across
the 460 pages of body. Check explicitly for:

- **Part I** — Chappe (p. 155), Bresson (p. 179), Office-Correspondance (p. 191), moment Villèle (p. 203), loi de 1828 (p. 236)
- **Part II** — *Constitutionnel* 3 jan. 1829 & *Débats* 29 jan. 1838 (p. 261), effet liste (p. 268), SGA (p. 348), scission d'octobre 1839 (p. 615)
- **Part III** — loi sur les signatures juillet 1850 (p. 408), Paton/Lauvray/Rousset (pp. 432, 441, 447), « l'identification crée l'identité » (p. 455), usines à bulletins (p. 574)

A note that hits none of these is an intro+conclusion summary, not a review of
the thesis.

## Two OCR traps that make correct citations look wrong

Both are documented inline in the gold and neither is a model error:

1. **Straddling quotes.** The first research question breaks across pages —
   p.20 ends `comment l'écriture`, p.21 begins `journalistique régulière…`.
   Page-level search finds it on *neither*. Cite `(pp. 20-21)`.
2. **Hyphenated words.** `constel-lation` on p.21 defeats substring search even
   though the citation is right.

When `verify_citations.py` reports WRONG, check for these before recording an
error. Roughly a third of the flags on the gold itself were false positives.
